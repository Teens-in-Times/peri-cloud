## 本批能力

QQ 内完成单选、多选、连续提问、文字回答、审批完整参数查看与一次审批；长结果保留全文，分页固定原任务；个人记忆、偏好、用量和已配置个人模型切换可直接操作。网页显示同一组状态和请求，作为可选入口。

提问超时、任务取消或通道失效使用 `InteractionResponse::Cancelled`；用户明确选择不回答才使用 `Rejected`。不通过空答案或假用户拒绝恢复模型。

完整操作表与后续范围见 [交互审计](qq-experience-audit-20261016.md)。本批不宣称运行中设备切换、历史任务列表、语音/文件和定时管理已全部完成。
