# v0.3.0 · 实例与工作区菜单

- QQ “菜单”提供实例选择、工作区浏览、会话权限、状态与取消入口。普通聊天继续只展示 AI 回复。
- 服务器本地实例作为可选部署配置，复用原生执行器、工具与会话审批，以云服务账号运行。
- 每个实例持久保存默认（全局）目录；省略路径使用默认值。保存默认目录不改变当前会话，切换工作区仍新建会话并保留权限与旧历史。
- QQ 与网页可发现子目录，分页浏览父目录、系统根 / 磁盘，以及使用历史目录或指定路径。不存在的默认目录不会阻挡系统根发现。
- 原生菜单回调使用 QQ 按钮事件引用发送下一张卡片；平台明确拒绝卡片时可使用 `/选 序号`，文字命令保留兼容。
- 按钮绑定实际聊天身份、路由、期限与预期会话，并防止重复消费。网页继续验证账号、同源与 CSRF；执行器仅验证运输和协议。
- 原有个人电脑 OAuth、任务身份与发件去重保持兼容。旧消息指纹及旧发件记录有兼容测试。

升级需同时更新云宿主和执行器。数据库新增 v4 表，升级前备份 SQLite 及配置；回退旧程序时也要恢复升级前状态快照。服务器本地实例不需要额外 OAuth 或 SSH。

Windows 与 Linux 原生程序由 GitHub CI 构建并运行原有回归和新增菜单、目录发现、服务器本地执行、审批、重启测试。QQ 协议集成使用模拟官方服务；具体机器人账号的真实按钮权限仍需人工验收。

下载后按 [部署指南](../setup.md) 配置自己的模型、QQ 凭据和连接。运行数据库、个人配置、令牌、历史与日志不在发布包内。
