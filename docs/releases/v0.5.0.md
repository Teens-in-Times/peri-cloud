# v0.5.0 · QQ 内交互、个人账号入口与公共访问控制

日常提问、选择、审批、结果找回和个人设置现在可以直接在 QQ 完成。官方 QQBot 继续保留，个人账号通过独立可选的 OneBot v11 入口接入，同用原有 Agent、账号与工具权限。

- 菜单正文保留完整名称和路径，长内容分页；编号与原生按钮操作同一动作。个人号支持引用菜单回复编号，跨群、跨用户、重复与过期操作不会获得授权。
- 单选、多选和连续提问保留草稿；审批可在 QQ 查看完整参数并允许一次或拒绝；`/结果` 取回原任务全文，不重新执行任务。
- `/网关` 在管理员私聊中管理每个入口的白名单与黑名单；允许用户、允许群、屏蔽用户和屏蔽群独立维护，黑名单优先，群聊白名单须同时允许用户和群。
- 名单修改持久保存、按版本核对并记录审计。网页提供管理员恢复入口。新适配器默认拒绝所有来源；官方 QQBot 显式保留原来的接入行为，可由管理员修改。
- 个人号只处理好友私聊、明确命令、群内 @ 和菜单引用；不处理整群闲聊、不自动加好友，不把不支持的附件静默转换为不完整任务。
- 设备连接保留 SSH 正反向线路，新增显式验证的 WireGuard 线路；线路切换不改变设备和任务身份，未知执行或投递结果不自动重放。

升级前备份状态目录。此版数据库升级至 **schema 7**，保留已有账号、设备、聊天关联、会话与个人设置；退回旧程序时必须恢复升级前的数据库备份。个人 QQ 协议端独立安装和扫码，不包含在发布包中。原有 `qq` 配置不需要替换；可选接入与名单设置见 [个人 QQ 接入](../onebot.md)、[网关访问控制](../gateway-access.md)。

验证以 Windows 云端、执行器、远程工具和进程回归、格式检查及严格 Clippy 为准；Linux 编译发布二进制并检查实际进程启动、鉴权和部署连接，不重复整套测试。发布包的 `BUILD.json` 记录精确源码提交与 CI 运行，`SHA256SUMS` 校验下载文件。

运行中切换执行设备、检索式长期记忆、自创 Skill、图片 / 文件 / 语音完整输入链路尚未在本版交付。协议与集成测试使用模拟 QQ 服务和真实 Agent / 执行器；个人账号的真实 QQ 展示和长期稳定性需扫码后单独验收。
