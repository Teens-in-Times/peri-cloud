# v0.4.0

一个云宿主可以接纳多个独立用户，并行执行各自的 Agent 会话。管理员通过 24 小时一次性邀请添加用户，设备 OAuth 和 QQ 关联流程保留。

- 每人独立保存聊天身份、设备池、会话、审批、回复偏好、文本记忆和模型凭据。
- 同一用户的多个 QQ / 网关身份共用设备池，各聊天独立选择实例、目录和权限。
- 服务器本地实例只属于原管理员；普通用户不能邀请成员或关闭服务。
- 用户可选择部署者配置的供应商、模型 ID 和自己的 API Key。密钥写入后不回显；下一轮生效。
- 全局 / 每用户并发、每日任务及逻辑模型请求额度、任务取消时限和个人数据限长。
- 可选独立 Linux 容器执行器，限制文件挂载、CPU、内存和进程数，继续复用原工具权限。
- 回环模型请求跳过系统代理，避免误转发凭据。
- 修复实例菜单回归测试依赖随机 UUID 排序的问题。

数据库升至 v6。原账号自动成为管理员，旧设备、OAuth 授权、QQ 关联和历史继续保留。升级前停服并保存一致备份；回退程序必须同时恢复旧数据库。

每日额度按 UTC 日界线统计。模型请求次数不是准确的 token / 金额账单。当前记忆是限长文本，尚不提供检索式记忆或历史存储配额。

部署方式见 [多用户指南](../multi-user.md)。Docker 执行器为显式可选项，容器仅能访问专用工作目录，不代替整个宿主的管理权限。
