# Peri 个人助手：会话成果与设计边界

日期：2026-10-18。状态：设计讨论记录，不表示下列新增能力已经实现。

本文件保存本轮对话成果。交互工作台为同目录的 `index.html`；浏览器中的修改需要导出 JSON 或带修改的网页才能携带到其他浏览器或交回项目。

## 本轮明确的方向

1. 对话与执行异步分离。主助手持久派发后即可继续正常聊天，不等待执行子任务的整个生命周期。
2. 主助手、执行 Agent 的推理与进程都在云端，本地仅保留执行器。物理进程数量、池化策略和 IPC 协议尚未确定。
3. 设备 Agent 可以拥有独立上下文；同设备内按任务或工作区进一步隔离，是待细化的设计建议。设备、项目授权与任务身份不能混为一谈。
4. 主助手保持对任务的理解，知道目标、约束、重要发现、阻碍与当前状态，并能继续讨论执行中的问题。
5. 主助手保留原生读写、搜索和执行能力。明确且短小的操作可以直接完成；需要较长工作现场或大量材料时选择委派。不是所有操作都必须经过子 Agent。
6. 所有操作沿用云端原 Agent 循环和 PermissionMiddleware。委派不扩大权限；执行器验证运输、绑定和身份，不成为第二套审批权威。
7. 任务状态和 trace 是一等可观测对象。运行时采集工具调用、结果、文件差异和已经输出的行动说明；无需强迫子 Agent 每隔几轮撰写汇报。
8. 允许主助手检查裁剪 trace，以及按需深入读取执行会话。Read 等大输出默认保留元信息、相关片段和原始引用；保留内容与重新读取的内容必须区分。
9. 可以每 N 轮向主上下文追加增量任务信息。N 的默认值、计数口径、字数预算、游标推进与无变化处理尚待决定。预览页中的数值是草案参数。
10. 完成、失败、需要输入等重要事件可以唤醒主助手；普通 trace 更新不必逐条触发模型或用户消息。用户正常聊天应优先获得处理机会。
11. 双向控制必要。主助手能向执行任务插话、追问、补充约束、请求暂停或取消；发送、读取和应用具有不同回执。
12. 运行时维护排队、运行、等待、结束、失败和未知等客观状态；Agent 的工作说明与语义判断另存，不能把自报“完成”当作验证成功。
13. 主助手和工作者需要有边界清晰、可版本化的提示词；提示词规定行为，归属、权限、并发、状态和去重仍由程序保证。
14. 共享任务记录不等同于长期记忆。个人偏好、设备事实、任务现场和完整审计分别保存、按授权读取。
15. 上下文按稳定前缀与持续追加组织；普通进展放尾部，阶段性压缩有明确边界。缓存有效期与命中率由供应商和实际请求决定，不能承诺常驻 Agent 就常驻 KV 缓存。
16. 云端任务由 Runtime 持有，QQ/Web 的连接或本轮聊天结束不终止任务。未知执行和未知投送均保留原身份，不自动重放。
17. 调度器保持独立 crate，只管时间与触发。主动联系走云端上下文、联系策略和 MessageAdapter/outbox；没有隐式创建的问候计划。
18. QQ 普通聊天显示 AI 正文；trace 是可查询的内部观察材料，不把执行流水逐条灌入普通对话。

## 仍待设计

- 主助手与工作者的进程部署、资源配额、前台容量保留及同工作区写入协调。
- 长期设备 Agent 身份和任务上下文的具体映射；并行任务、跨设备交接及恢复规则。
- N 的计数来源、配置范围、默认值与上下文预算；重要事件合并及前台消息仲裁。
- trace 的字段、裁剪、原文保留期、脱敏、分页与查询授权。
- 插话在工具批次边界的消费、约束版本检查、暂停和取消的确认语义。
- 工具正式名称和参数。本工作台中的 delegate_task / inspect_task / message_task / control_task 均为候选接口。
- 记忆后台候选、整理和 Skill 晋升的后续实现；独立项目授权尚未交付。

## 保留但不作为唯一方案

- 同一长历史内 A → B → A 的执行 segment 设计：可作为原有设计参考，不能单凭环境横幅解决全部上下文污染。
- 单 Agent 多份可恢复工作上下文：仍是可选实现，不强制每台设备一个常驻操作系统进程。
- 子 Agent 的语义进度更新工具：可用于记录重要发现，不要求固定频率汇报，不能改写宿主客观生命周期。

## Grok 参考的证据边界

Grok Bot 官方行为、0.18 运行时档案和 Grok Build 官方源码分别标记。Bot 参考图是逻辑结构，不声称还原了云服务部署。Bot 的账号共享电脑也不同于 Peri 的多执行器设备池。

Build 的 capture / consolidation 仅作为记忆流水线参考，不冒充 Bot 已公开的后台记忆实现。Bot 的云端队列、调度、长期事实记忆和最终投送协议仍存在未确认部分。
