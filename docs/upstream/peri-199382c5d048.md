## 保持的 Cloud 契约

- Cloud schema 仍为 26，不重置或迁移生产数据库。执行身份、任务/轮次/窗口、设备与原生 invocation ID 的归属不变。
- 主助手仍使用摘要压缩；执行者仍使用宿主硬窗口，关闭自动 compact 的配置优先于新增常驻预算，不借上游代码为执行者打开 Full 摘要。
- 原 PermissionMiddleware、任务审批、OAuth 人工授权和设备修改互斥保持。MCP 取消超时不证明执行已停止，旧操作/投递结果未知时仍查询原身份，不盲目重放。
- 本轮没有开放 worker 外部 MCP、项目 `.mcp.json`、远端 Agent 或新的账号共享范围。
- 任务历史不整体写入长期个人记忆，隐私失效及来源会话边界不放宽。

这批 SDK 优化不代表 [Issue #9](https://github.com/Teens-in-Times/peri-cloud/issues/9) 的 CloudJournal 历史分页与内存治理已经解决：Cloud 仍保存完整 canonical 会话 JSON，生产 RSS 与长会话量测尚需单独完成。
