# Peri Cloud

支持多个独立账号的云 Agent：推理循环在服务器，工具在各自选择的 Windows / Linux 实例上执行，官方 QQBot 与可选的个人 QQ / OneBot 是并存的聊天入口。服务器本地实例仅属于管理员。

本项目基于 [Peri](https://github.com/KonghaYao/peri) 的 Rust Agent 核心，拆出原生执行器并加入账号、设备连接、网关和常驻服务。发布包不包含 TUI。保留依赖所需的编译期提示词与 workflow 资源。当前版本 `v0.7.0`（Peri v4 核心），仍处于预览阶段。

## 能做什么

- 云端运行原有 Agent 推理循环；模型可直接使用 OpenAI Chat Completions 或 Anthropic Messages。外部 API 聚合服务是可选部署集成，不是 Peri 内置依赖。
- 管理员通过一次性邀请创建成员账号。每人拥有独立的会话、审批、聊天关联、设备池、记忆和模型配置。
- 每个用户可以绑定多个 QQ / 网关身份，共用自己的设备池；各聊天会话可独立选择实例与工作区。
- 不同用户的任务可以并行；支持全局 / 每用户并发、每日对话和模型请求额度，以及任务时限。
- 网页可设置个人回复偏好、长期记忆、模型；独立部署可填写自己的 URL、协议和 Key。可选对接既有 New API，统一渠道管理与调用出口；密钥不回显、不进入工具参数。
- 网页与 QQ 共享会话、工作区、任务提交、取消、审批和结果；控制操作不需要先调用模型。
- Windows 和 Linux 执行器提供 Read、Write、Edit、Glob、Grep、Bash，复用同一套工具代码。
- 在个人电脑浏览器登录，使用 OAuth 授权码 + PKCE S256 绑定执行器；Windows 登录凭据使用 DPAPI，Linux 使用权限受限的文件。
- 在网页生成五分钟有效的一次性口令，在 QQ 发送 `/绑定 口令`，再回到网页核对并确认聊天账号。
- QQ 显示 AI 回复；需要审批时发送简短工具摘要及“允许一次 / 拒绝”按钮，完整参数可直接在 QQ 分页查看，网页为可选入口。
- QQ 发送“菜单”即可选择实例、浏览工作区目录、切换权限和查看状态；卡片回调回复绑定点击事件，避免把多层浏览挤在同一条用户消息的回复额度内。
- 菜单正文保留完整选项；长名称使用编号按钮，超长内容可发送 `/菜单详情` 在 QQ 内分页查看。历史工作区保留完整路径，支持前后翻页。个人号的附加 OneBot 网关已实现，支持群内 @、完整文字菜单、菜单引用编号及原有审批；配置与边界见 [个人 QQ 接入](docs/onebot.md)，比较依据见 [调研与交互设计](docs/qq-menus-and-personal-bots-20261016.md)。
- 可启用仅管理员可用的服务器本地实例；也可使用独立容器执行器，限制挂载目录、内存、CPU 和进程数。
- 权限属于当前聊天会话，云端复用 Peri 的工具权限机制。执行器不重复弹出工具审批。
- 原生 HTTP 工具协议支持回环 SSH 正向 / 反向隧道，以及显式验证的 WireGuard 私网线路；同一设备优先 WireGuard、SSH 备用，凭据和线路配置不进入模型参数。
- 持久化会话、任务、审批及发件记录；连接中断或结果未知时，不盲目重新执行工具或重复发消息。
- 网页和 QQ 可以浏览目录、系统根 / 磁盘、历史工作区，并指定路径；不指定时使用每个实例保存的默认（全局）工作区。切换会话目录保留权限与旧历史。
- 账号工作台提供设备撤销、聊天账号移除、关联请求确认、操作审批和云服务关闭入口。
- 执行器在反向 SSH 建立后自动上报回环连接租约；工作台显示在线/离线/未配置，登记本身不再被当作在线。网页对话持久化，刷新或多标签不会丢消息或重复执行。

各入口的来源限制由网关公共层执行，规则可在管理员私聊菜单修改，并保存版本和审计记录；新增个人入口默认拒绝，群聊须同时允许用户与群。见 [网关访问控制](docs/gateway-access.md)。

## 下载与构建

在 [最新 Release](https://github.com/Teens-in-Times/peri-cloud/releases) 下载 Windows x86_64 或 Linux x86_64 压缩包，并使用 `SHA256SUMS` 校验。目录浏览与服务器本地实例需要 `v0.3.0`。Linux 二进制在 Ubuntu 22.04 x86_64 上构建、验收；其他架构请从源码编译。

多用户、个人模型、个人记忆和资源额度从 `v0.4.0` 起提供。升级前备份状态数据库，见 [升级与回退](docs/multi-user.md#升级与回退)。

维护者发布 Windows 二进制时可使用 `scripts/build-release.ps1 -CargoHome C:\BuildCache\peri-cloud`。使用不含个人账号名的 Cargo 缓存目录，避免 C 依赖记录个人源码路径；MSVC 的 PDB 引用由构建脚本保留为文件名，参见 [Microsoft 文档](https://learn.microsoft.com/en-us/cpp/build/reference/pdbaltpath-use-alternate-pdb-path)。`PDB` 文件不进入发布包。

发布包包含 `peri-cloud-host`、`peri-executor`、许可证、配置示例和文档。配置示例中的域名、模型名称和设备 UUID 都是占位值，下载后需要自行配置。

需要 Rust 1.99+、平台 C/C++ 编译工具和 OpenSSH 客户端。Windows 构建使用 MSVC；Linux 构建需要 C/C++ 编译器、CMake、pkg-config 等基础开发工具。工作区固定 `rmcp` 版本并附带任务订阅补丁；使用包装脚本让 Cargo 应用该补丁。

```sh
./scripts/cargo-rmcp-patched.sh build --release --locked -p peri-cloud --bin peri-cloud-host -p peri-executor --bin peri-executor
```

## 开始使用

1. 在云服务器配置模型、QQ 环境变量以及 `host.json`，启动 `peri-cloud-host --config host.json`。
2. 在个人电脑启动执行器，并配置设备发起的反向 SSH 隧道。
3. 使用执行器的 `login` 入口，在本机浏览器创建 / 登录账号并确认设备授权。
4. 把执行器设备 UUID 与运输令牌配置到云端连接表。OAuth 登记设备和实际 SSH 通路是两个步骤；登记成功不代表执行器已经在线。
5. 在工作台生成关联口令，在 QQ 绑定后回到网页确认；发送“菜单”，点击选择实例，然后直接交代任务。

完整命令与令牌配置见 [部署指南](docs/setup.md)，架构与权限边界见 [架构说明](docs/architecture.md)。

双线路配置、在线设备探测与主控迁移见 [执行器连接与控制面迁移](docs/transports.md)。

多用户邀请、个人模型与额度配置见 [多用户部署指南](docs/multi-user.md)。一个服务进程运行多套独立会话，复用 Agent 代码；不同用户的历史不会混入同一条推理上下文。

## QQ 常用操作

| 命令 | 用途 |
| --- | --- |
| `/new` / `/compact` / `/clear` | 新会话、摘要压缩、清空当前上下文 |
| `/history` / `/resume 会话ID` | 查看与恢复历史会话 |
| `/loop 目标` / `/rewind 消息ID --no-revert-files` | 原生循环目标与纯上下文回退 |
| `/help` / `/commands` | CLI 命令用法；`/help all` 查看全部原生入口的接入状态 |
| `菜单` / `/菜单` / `/帮助` | 打开操作卡片 |
| `实例` / `/实例` | 打开实例选择卡片 |
| `/选 序号` | 平台拒绝原生按钮时，选择最近一张菜单的选项 |
| `/绑定 口令` | 请求关联当前聊天账号 |
| `/电脑` | 实例选择的兼容入口 |
| `/连接 实例ID [绝对路径]` | 兼容文字操作；省略路径使用实例默认目录 |
| `工作区` / `/工作区` | 打开目录选择卡片 |
| `/工作区 绝对路径` | 切换目录，开始新会话并保留权限 |
| `/权限 默认` | 默认权限模式，按工具策略审批 |
| `/权限 编辑` | Peri 的编辑权限模式 |
| `/权限 全部` | 当前会话允许全部工具；仅用于你信任的任务 |
| `/状态` | 查看会话状态 |
| `/取消` | 请求停止当前任务 |
| `/问题` / `/回答 内容` | 连续提问、单选、多选和文字回答 |
| `/详情 审批码` / `/允许 审批码` / `/拒绝 审批码` | 在 QQ 查看参数并审批本次操作 |
| `/结果` / `/菜单详情` | 查看原任务结果与完整菜单分页 |
| `/网关` | 管理员私聊管理各入口的白名单、黑名单和响应范围 |

QQ 原生按钮是否可用取决于机器人平台权限。网关按平台实际提供的点击者身份验证审批归属；按钮使用 Hermes 兼容的权限类型，后台仍严格核对账号、会话、设备、请求和期限。平台明确拒绝原生卡片时可在 QQ 使用 `/详情`、`/允许` 和 `/拒绝`；投递结果未知时不重复发送。

## 验证

日常修改以 Windows 测试、格式检查和 Clippy 为准；通过后不在 Linux 重复运行同一套测试。Linux 用于发布编译和部署后的启动、鉴权及连接检查，除非明确要求额外的平台专项验证。

核心验证命令：

```sh
chcp 65001   # Windows：让 PowerShell 中文输出按 UTF-8 解码
./scripts/cargo-rmcp-patched.sh test --locked -p peri-cloud -p peri-executor -p peri-remote-tools -p peri-tool-runtime -p peri-process
./scripts/cargo-rmcp-patched.sh clippy --locked -p peri-cloud -p peri-executor --all-targets --no-deps -- -D warnings
```

测试使用模拟模型与 QQ 服务，不需要真实 API 密钥。JS 执行及其他继承的扩展模块可能需要各自的额外运行环境；上述测试聚焦本项目交付的云端和设备执行链路。

## 当前限制

- 尚未提供远程开机 / Wake-on-LAN 的常驻家中节点。
- Linux 核心工具可运行，完全无人值守服务器的 OAuth 登录体验仍需完善。
- Windows 提供用户登录后的启动方式，尚未提供经过验收的登录前系统服务安装器。
- 设备连接可由执行器自动上报；静态 `devices` 配置仍作为回退，首次登录与部署配置仍需按指南完成。同一任务中由模型自动切换执行设备的工具尚未提供。
- 官方 QQBot 与可选 OneBot v11 适配器可以同时使用；个人号的扫码与真实客户端需单独验收。微信适配器和检索式长期记忆后端属于后续扩展；当前记忆为按账号保存的限长文本。
- 额度统计逻辑模型请求次数，包含上下文压缩；尚不提供准确的 token / 金额计费或用户历史存储配额。
- 一个状态目录只能由一个云服务进程持有；并行任务不代表可同时启动多个共享 SQLite 的宿主。
- 原生 QQ 按钮已有协议、归属验证和进程集成测试；不同机器人账号的真实平台权限需要分别验收。

执行器以启动它的系统账号运行，能够访问该账号可访问的文件并执行命令；它不是安全沙箱。会话审批是工具权限入口。只绑定你控制的聊天账号和设备，并保护执行器运输令牌、SSH 密钥及云端配置。
